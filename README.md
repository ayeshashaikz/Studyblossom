# StudyBloom

A cozy, glassmorphic study dashboard built with Vite + React + TypeScript,
Tailwind CSS, and Framer Motion.

## Getting started

```bash
npm install
npm run dev
```

Then open the URL Vite prints (defaults to http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Stack

- Vite + React 18 + TypeScript
- Tailwind CSS
- Framer Motion (animations)
- lucide-react (icons)
